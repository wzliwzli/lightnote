轻笺 Lightnote v1.3 —— 桌面备忘录 / 待办
==========================================

一个轻量、清爽、本地优先的待办应用。不联网、不登录、数据只存在你自己电脑上。


怎么用
------

1. 把压缩包解压到任意文件夹（比如 D:\Lightnote）。
   注意：Lightnote.exe、web 文件夹、几个 dll 必须放在一起，不能只拷 exe。

2. 双击 Lightnote.exe。
   打开后是屏幕右下角的悬浮小窗，不占任务栏，只收在托盘（右下角小三角里）。

3. 想放桌面：右键 Lightnote.exe → 发送到 → 桌面快捷方式。

4. 退出：右键托盘图标 → 退出轻笺。
   点窗口上的 × 只是隐藏到托盘，不是退出。


被 Windows 拦住了？
-------------------

这个 exe 没有购买代码签名证书，从网上下载后被 Windows SmartScreen 标记为
"未知发布者"是正常现象，不是病毒提示。

放行方法，二选一：

  A. 右键 Lightnote.exe → 属性 → 底部勾选「解除锁定」→ 确定，然后再双击
  B. 双击后点提示框里的「更多信息」→「仍要运行」

如果公司电脑策略不允许放行，直接用浏览器打开 web\index.html 也能用，
功能完全一样，只是没有悬浮窗和托盘常驻。

校验文件有没有损坏：PowerShell 里执行
  Get-FileHash .\Lightnote-win64-v1.3.zip -Algorithm SHA256
和 SHA256SUMS.txt 里的值对一下即可。

遇到杀毒软件误报，可以把这个文件上传到 https://www.virustotal.com 看看，
或者直接在 GitHub 仓库提 issue：https://github.com/wzliwzli/lightnote/issues


两种窗口
--------

悬浮窗（默认）
  - 拖标题栏移动，拖四条边调整大小，位置和尺寸会记住
  - 点右上角的 ⤢ 展开成完整窗口
  - 透明度可调（设置 → 悬浮窗透明度），完整窗口始终不透明

完整窗口
  - 侧栏、标签筛选、设置都在这里
  - 右上角有最小化 / 最大化 / 隐藏按钮
  - 按 Ctrl M 或点标题栏的收缩按钮可以收回悬浮窗


常用操作
--------

输入    Enter 保存
        语法：!! 紧急   ! 重要   * 置顶   #标签（可写多个）
        例：!! #工作 #周报 周五前交初稿
编辑    双击标题
备注    悬停卡片点便签图标
日期    悬停卡片点日历图标（可同时设重复：每天/每周/每月）
删除    悬停卡片点垃圾桶（5 秒内可撤销，或 Ctrl Z）
搜索    Ctrl K
收起/展开 Ctrl M
保存备注 Ctrl Enter


数据存在哪
----------

%LOCALAPPDATA%\Lightnote\
  WebView\        应用数据（任务、设置都在里面）
  float-pos.txt   悬浮窗位置和大小
  full-bounds.txt 完整窗口位置和大小

备份：设置 → 拓展设置 → 导出 JSON。
换电脑：把上面整个 Lightnote 文件夹拷过去即可。


系统要求
--------

Windows 10 1803 及以上 / Windows 11。
用的是系统自带的 WebView2 运行时（Win11 和大多数 Win10 都已预装）。
如果提示缺少 WebView2，装一下微软的 "Microsoft Edge WebView2 Runtime"。
